1 · Page properties (the first block)

tags:: [[TUI]]
alias:: [[Spotify TUI Options]]

- # Spotify [[TUI]] Projects
Spotify/Tool/TUI
tags:TUI
alias:Spotify TUI Options

Leading key:: value lines before the first - form the pre-block, drawn as div.page-properties: bg #f8f9fa, padding 4px 8px, margin 4px 0, radius 4. Each row is key : .page-property-value. The key is itself a link to the property's page (.page-property-key, weight 500, secondary text colour). tags and alias values are split on commas and each becomes a page link without brackets.

2 · Other values keep their inline markup

created-by:: [[Person/Nicholas Marriott]]
logseq-entity:: [[Logseq/Entity/Software/Project]]
created-by:[[Person/Nicholas Marriott]]
logseq-entity:[[Logseq/Entity/Software/Project]]

Values that aren't comma-split are rendered as inline text, so [[…]] keeps its grey brackets (:ui/show-brackets? defaults to true). Quoted values lose their quotes; integers and dates print as-is.

Indented key:: lines under a block render inside it as div.block-properties (same box). Never shown: id, collapsed, heading, background-color, created-at, updated-at, query-*, hl-*, ls-type, task markers, and the card-* scheduling keys. A block with only hidden keys gets no box at all.

4 · Keys that change the page instead of showing

title:: tmux
public:: false
alias:: [[Spotify TUI Options]]
title:: replaces the filename-derived name as the page title and the name every link resolves to.
public:: false withholds the whole page from the published site (with :publishing/all-pages-public? true).
Visiting an alias opens the original page; the alias also collects its own backlinks into that page's Linked References.

Page name precedence: title:: → filename with ___ read as / (URL-decoded). Names compare case-insensitively; routes use the lower-cased name: #/page/spotify%2Ftool%2Ftui.
