1 · Files become namespaced pages

# a child names them
tmux/Command/new-session
Title is the full original name, slashes included.

___ in a filename is / in the page name (older gardens use %2F or .; see :file/name-format). Every prefix (tmux/Command) is a real page even with no file: it opens, shows no blocks, and still gets Linked References and Hierarchy.

3 · On a child page

# on page: tmux/Config
Hierarchy
  • [[tmux]]/[[Config]]
  • [[tmux]]/[[Config]]/[[local]]

The list unions the page's descendants with its ancestor routes, de-duplicated and sorted. A leaf with no children still shows one row: its own full path, which doubles as a breadcrumb back up. A page with no / and no children has no Hierarchy section. If the page is an alias, the first namespaced alias is used.
