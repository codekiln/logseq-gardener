## Why

Readers cannot tell what “linking pages” and “references” mean when both counts are identical. A compact summary should show how many source pages link here and explain additional referring contexts only when useful.

## What Changes

- Show a source-page count in the collapsed heading, including zero and filtered totals.
- Show a separate context count when page and context counts differ, with a short explanation.
- Shorten filter instructions to “Include or exclude selected related pages.”

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `published-linked-references`: compact count presentation and concise filter instructions, preserving existing indexing and filtering behavior.

## Impact

Shared backlink HTML and browser count updates, with generic publication and filter fixtures. No index or host integration API changes.
