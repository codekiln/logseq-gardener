# GitP appearance experiment

This experiment checks custom CSS against real podcast chapters, waveforms, audio controls, dialogue, manuals, and preset links. `episode.css` gives the generated pages a dark background, wider recording controls, and larger chapter headings.

## Reproduce

Use a clean garden checkout at [0160eaba — docs: file Claude vs ChatGPT secrets management question](https://github.com/codekiln/logseq-encode-garden/commit/0160eaba4d7849f40bc7734aaa9f737b64b67948). This revision supplies the approved October 18 and October 20 episode pages with `public:: true`, along with the manuals and presets used in the experiment. Set `GARDEN_SOURCE` to that checkout and `SITE_OUTPUT` to a fresh directory with an existing parent outside the garden. From the renderer repository root:

```sh
mise exec -- cargo run -- publish \
  --graph "$GARDEN_SOURCE" --output "$SITE_OUTPUT" \
  --filename-format triple-lowbar \
  --include GitP/A/Session/26/10/18-Sun \
  --include GitP/A/Session/26/10/20-Tue \
  --include GitP/Acolyte \
  --include Microfreak/UG --include Launchpad/UG --include Zoom/H5 \
  --include 'Microfreak/Preset/075 Saying Goodbye' \
  --include 'Microfreak/Preset/077 Eonz' \
  --include 'Microfreak/Preset/174 Auster' \
  --stylesheet "$PWD/openspec/changes/custom-site-stylesheet/experiments/gitp-appearance/episode.css" \
  --format json
```

Open the output's `index.html` locally, then choose either episode. Compare with a second fresh output generated by the same command with `--stylesheet` omitted. The stylesheet is loaded by the index and both episodes. The generator fetches no remote content; viewing episode images or playing recordings uses the hosted URLs already present in the selected source.

## Results

The styled export generated 587 pages, zero copied garden assets, and 469 diagnostics. Diagnostics cover unsupported or unresolved constructs across selected manuals and pages; publication succeeds with visible fallbacks. The October 20 episode contains 12 audio controls and 11 chapter waveform images. Every generated HTML file includes the stylesheet after built-in CSS, and the copied file matches `episode.css`.

Browser inspection compared the plain white baseline with the styled export. The episode showed the custom background and palette, larger heading, full-width audio controls, waveform above its nested player, readable dialogue, and manual links. The index used the same custom background, typography, and link colors.

The index remains a flat list of selected page names, including technical asset names. Custom navigation, an editorial homepage, and HTML templates require further renderer work. CSS provides appearance customization within the existing document structure.
