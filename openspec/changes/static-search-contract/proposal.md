## Why

Static garden visitors need to find published page titles and original content. A shared, versioned search contract gives the forthcoming dialog stable destinations and the same publication privacy boundary as the renderer.

## What Changes

- Add opt-in generation of deterministic page and original-content search records.
- Publish an external manifest, fingerprinted corpus and independent pure JavaScript query evaluator.
- Emit source anchors for indexed original content and document host route adaptation and exclusion options.

## Capabilities

### New Capabilities

- `static-search-contract`: Selected-source search records, stable destinations, bounded deterministic evaluation and revision validation.

### Modified Capabilities

None.

## Impact

The SDK publication options, CLI publish options and generated site assets gain opt-in search support. The search dialog and measured browser loading policy follow in separate issues. Implements [issue94 — static search index](https://github.com/codekiln/logseq-gardener/issues/94) under [issue93 — static garden search](https://github.com/codekiln/logseq-gardener/issues/93).
