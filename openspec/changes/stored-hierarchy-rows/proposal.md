## Why

Generated intermediate namespace rows repeat destinations already linked from stored descendant paths. Readers need a shorter hierarchy that retains every published source page and its namespace links.

## What Changes

- Show the current page and all selected stored descendants at every depth.
- Keep generated namespace destinations reachable through path segments and the complete index.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `published-namespace-hierarchy`: omit generated-only descendant rows while preserving current-page navigation and stored descendants.

## Impact

Shared hierarchy presentation and publication fixtures. Source selection, routes, content and page counts remain intact.
